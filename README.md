# 每日热量计算器 · 云端版

一个单文件的中式饮食热量计算器：内置 200+ 条中式食物库，支持在线查询包装食品、
拍照识别营养成分表，自动计算 BMR / TDEE / BMI 与每日目标热量。

数据保存在云端账号下，换设备登录同一邮箱即可继续。

## 功能

- **今日饮食**：关键词/条码搜索食物，自动汇总热量与三大营养素，对照目标给出建议
- **我的数据**：性别 / 年龄 / 身高 / 体重 / 活动水平 → BMR、TDEE、BMI、目标摄入
- **拍照录入库**：拍照识别营养成分表（本地 OCR 离线免费 / 视觉大模型更准），
  校对后存入自建食物库，支持照片留存
- **自建食物库**：跨设备同步，支持导出 JSON / CSV

## 技术实现

- **单文件应用**：整个应用就是一个 `index.html`，无构建步骤，双击即可运行
- **后端**：WorkBuddy 云服务（认证 + 数据库 + 对象存储）
- **SDK 内联**：云服务 SDK 直接内联进 HTML，不走 CDN
  （部分浏览器的跟踪防护会拦截第三方 CDN 脚本访问 storage，导致登录静默失败）
- **数据隔离**：所有表均以 `owner_id` 归属用户，行级安全策略确保用户只能读写自己的数据

### 数据库表

| 表 | 用途 |
|---|---|
| `profiles` | 身体数据、目标、BMR / TDEE 计算结果 |
| `food_logs` | 每日饮食记录（日期、克重、热量、三大营养素） |
| `custom_foods` | 自建食物库（含营养成分表照片的对象存储路径） |

三张表均为 `owner_id TEXT DEFAULT auth.uid()` + RLS 行级安全，
客户端不发送 `owner_id`，由数据库填充并强制校验。

## 本地运行

```bash
python -m http.server 8000
# 或 npx serve .
```

打开 `http://localhost:8000`。

**注意**：本地打开时会**自动跳转到官方地址**（因为云服务只放行官方域名）。
若想留在本地查看源码页面，在网址后加 `?stay=1`：

```
http://localhost:8000/?stay=1
```

## 隐私

- 只收集用于热量计算所必需的数据（邮箱、身高体重等）
- 数据存储在自己的云端账号下，其他账号无法读取（行级安全策略保证）
- 拍照上传的营养成分表照片仅本人可见
- 可随时通过导出功能取回全部数据
